PhasorPy 0.13 (2026-11-06)
==========================

This is the fourth beta release of the PhasorPy library.
It contains new functions, support for Python 3.15, improved tutorials,
and many bug fixes.

The new ``cluster.phasor_cluster_kmeans`` function partitions phasor
coordinates into clusters using k-means clustering.

The ``io.signal_from_fbd`` function passes keyword arguments to
``FbdFile`` and ``FbdFile.asimage``.

Wheels are now available for free-threaded Python 3.15 and Pyodide.

This release supports Python 3.12 through 3.15.
